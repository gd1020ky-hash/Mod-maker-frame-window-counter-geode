# NaN GD Frame Window Counter (Android Only) 📱

A native Geometry Dash Android mod built using the **Geode Framework**. It implements real-time 240Hz frame window input calculations inspired by YouTube showcase creator **NaN GD**.

## Features 🚀
* **Dynamic Visual Rings:** Renders expanding, color-coded rings over the player icon whenever an input transition occurs.
* **Pitch-Adaptive Audio:** Triggers a dynamic bell sound effect. Crucially, the pitch drops lower as the input window scales down (1-Frame perfect clicks feature a deep, heavy bell punch).
* **NaNDL Continuous Precision HUD:** Real-time on-screen counter display monitoring your exact baseline σ/s density score.

## Installation Details 🛠️
1. Download the compiled `.geode` package from the **Actions** tab artifacts bundle.
2. Open the **Geode Menu** directly on your Android phone's main screen layout.
3. Access your local settings panel, tap **Install from File**, and select the mod package.
4. Enjoy your frame window counter
